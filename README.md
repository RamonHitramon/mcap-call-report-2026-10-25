# MCAP Research · 2026-10-25

Static, public report of historical crypto-call paper simulations. No login, wallet connection or live API is required to view the report.

- SOL mode: 21 Solana calls, total starting bankroll 1 or 2 SOL, editable position size, fees, gas and slippage; cash-constrained chronological simulation.
- USD reference: 23 calls (21 Solana, 2 Robinhood), independent equal-stake comparisons.
- Targets: +10%, +20%, +30%, +50%, 2x, 3x, 5x, day-close hold and partial exits.

All costs are illustrative assumptions, not measured transaction expenses. Prices, time resolution, converted-SOL approximations, stale marks and execution limitations are disclosed in the report. This is not a statement of actual trading profit or an investment recommendation.

The repository contains only whitelisted public report assets and market data. Credentials and private operational state are not included.
